# Description

In collaboration between the [Center for Astrophysics | Harvard & Smithsonian](https://www.cfa.harvard.edu/) and [Università di Milano](https://astro.fisica.unimi.it/),
we are developing an interactive data archive website for the [neutron star interior composition explorer](https://heasarc.gsfc.nasa.gov/docs/nicer/) (NICER) X-ray telescope.
The website allows users to easily access and explore the data collected by NICER, including light curves, spectra, power density spectra, hardness intensity diagrams, and other relevant information.
The website features a user-friendly interface, advanced search capabilities, and interactive visualisations to facilitate data analysis and interpretation.
We plan to incorporate unsupervised machine learning models to provide users with insights into the data, such as clustering and anomaly detection, to help identify interesting features and patterns in the data.
The website is built using the [Django](https://www.djangoproject.com/) web framework with a [PostgreSQL](https://www.postgresql.org/) database backend.
