# Description

We designed a 3U CubeSat that was shortlisted as top-5 nationwide in the [LaunchUK Nanosat Design Competition](https://web.archive.org/web/20230206081417/https://www.gov.uk/government/news/apprentices-among-those-shortlisted-in-600000-climate-satellite-design-competition).
The satellite collects soil moisture data using signals-of-opportunity, an efficient alternative to traditional satellite methods that require large antennas.
Soil moisture data is used to monitor peatland health, which is a key factor in reducing greenhouse gas emissions in the UK.
The mission also includes a secondary drag-sail payload designed to address satellite orbital decay challenges.
