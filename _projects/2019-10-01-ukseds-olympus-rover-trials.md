# Description

We designed a Martian rover for the [UKSEDS Olypus Rover Trials](https://ukseds.org/ignition/competitions/olympus-rover-trials/) competition, coming first nationwide in 2020 and 2021, along with the best mission design, presentation, and critical design review awards.
The rover was tasked to solve various problems from navigating complex Martian terrain to using robotic arms for obtaining samples.
The software was developed using Rust for efficient compute on a Raspberry Pi, along with simulations run using [Webots](https://cyberbotics.com/), and a webinterface using Vue and remote controllers.
We were developing an autonomous pathing system that used stereoscopic vision and A* pathing to plan the safest path to the objective.
